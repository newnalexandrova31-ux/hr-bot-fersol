# Описание проекта: HR-бот

## 1. Назначение проекта
**HR-бот** — это интеллектуальный ассистент для сотрудников компании, разработанный для автоматизации ответов на типовые вопросы, связанные с кадровыми процедурами, регламентами и внутренними документами. Бот позволяет разгрузить HR-отдел, предоставляя пользователям мгновенный доступ к корпоративной базе знаний в режиме 24/7.

## 2. Основные функции
*   **Ответы на вопросы:** Бот понимает естественный язык и ищет ответы в базе знаний компании.
*   **Интеграция с Excel:** В качестве базы данных используется файл формата `.xlsx`, что позволяет HR-специалистам легко обновлять информацию без привлечения разработчиков.
*   **Использование ИИ (RAG):** Бот использует технологию Retrieval-Augmented Generation для формирования точных и контекстуальных ответов на основе предоставленных данных.
*   **Уведомление администратора:** Все запросы пользователей и ответы бота пересылаются администратору для мониторинга качества работы и выявления пробелов в базе знаний.
*   **Поддержка Markdown:** Бот форматирует ответы для удобства чтения в Telegram.

## 3. Целевая аудитория и сценарии использования
### Целевая аудитория:
*   Новые сотрудники в период адаптации (онбординг).
*   Текущие сотрудники, ищущие информацию о регламентах.
*   HR-менеджеры, стремящиеся оптимизировать обработку рутинных запросов.

### Сценарии использования:
1.  **Запрос о процедурах:** "Как оформить отпуск?" или "Каков процесс получения справки 2-НДФЛ?".
2.  **Поиск шаблонов:** "Где найти шаблон заявления на увольнение?".
3.  **Информирование о льготах:** "Какие условия ДМС в нашей компании?".
4.  **График работы:** "До скольки работает офис в пятницу?".

## 4. Используемые технологии
*   **Язык программирования:** Python 3.10+
*   **Библиотека бота:** [aiogram](https://docs.aiogram.dev/) (асинхронный фреймворк для Telegram Bot API).
*   **Обработка данных:** [pandas](https://pandas.pydata.org/) и [openpyxl](https://openpyxl.readthedocs.io/) для работы с Excel-таблицами.
*   **Искусственный интеллект:** [OpenAI SDK](https://github.com/openai/openai-python) для взаимодействия с моделями через сервис [OpenRouter](https://openrouter.ai/).
*   **Языковая модель:** Gemini 1.5 Flash (или аналогичные через OpenRouter).
*   **Управление конфигурацией:** [python-dotenv](https://github.com/theskumar/python-dotenv) для работы с переменными окружения.

## 5. Архитектурные решения
*   **Простая RAG-архитектура:** Вместо сложной векторной базы данных используется прямой импорт текста из Excel в контекст LLM. Это оптимально для баз данных малого и среднего объема (до 1 МБ), обеспечивая высокую скорость разработки и простоту поддержки.
*   **Кэширование базы знаний:** Текст из Excel считывается один раз при первом запросе и кэшируется в оперативной памяти, что минимизирует количество операций ввода-вывода.
*   **Асинхронность:** Весь сетевой ввод-вывод (Telegram API, OpenRouter API) реализован асинхронно для обеспечения отзывчивости бота.
*   **Безопасность:** Конфиденциальные данные (токены, API-ключи) вынесены в файл `.env` и не хранятся в коде.
